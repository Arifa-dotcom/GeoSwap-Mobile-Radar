# GeoSwap-Mobile-Radar

GeoSwap is a cross-platform mobile application designed for money-less bartering via real-time proximity. By utilizing a "Barter Radar" that identifies items within a 5km radius and a smart algorithm for 3-way trade loops, GeoSwap solves matching gaps in local communities. It leverages live GPS to facilitate instant, face-to-face trading, promoting a sustainable circular economy.

## 🚀 Key Features
* **Barter Radar:** Real-time discovery of available items within a 5km range using live GPS.
* **Smart Matching:** An intelligent algorithm that detects and enables 3-way trade loops to solve complex matching gaps.
* **Community-Focused:** Encourages local, face-to-face interactions to foster a sustainable community economy.
* **Money-less Trading:** A dedicated platform for swapping goods without the need for currency.

## 🛠 Technical Stack
* **Platform:** Cross-platform mobile development.
* **Core Logic:** Smart matching algorithm for multi-party trade loops.
* **Location Services:** Integration with live GPS for real-time proximity tracking.
* **Architecture:** Scalable design focused on low-latency data updates.

## 💡 The Problem Solved
Traditional bartering is often limited by two-way matching (Person A has what B wants, and vice versa). GeoSwap removes this limitation by calculating 3-way loops (Person A -> B -> C -> A), significantly increasing the success rate of trades and reducing waste.
